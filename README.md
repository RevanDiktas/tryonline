# Tryon

**3D virtual try-on for fashion e-commerce.** Shoppers see themselves wearing a
brand's actual clothes on a 3D avatar before they buy. Brands add it to their
store, cut the fit-driven returns that wreck margins, and get fit analytics no
other tool gives them.

Tryon is the first product of [Fravash](https://fravash.ai). Live in market at
[tryon.global](https://tryon.global).

---

## The problem

Fit and sizing drive roughly 45% of all fashion returns. Each return costs a
brand real money in reverse logistics before markdown. Shoppers can't tell how
something will actually fit from a flat photo on a straight-size model, so they
over-order and send the rest back.

## What it does

- Turns a shopper photo into a personalized 3D body.
- Puts a brand's real garments on that body so the shopper sees true fit, not a
  flat overlay.
- Gives brands fit intelligence: where a size run fails, and who sizes up or
  down.

The body becomes a portable fit profile the shopper reuses across brands, so the
product compounds in value with each store added.

## Stack

Next.js frontend, FastAPI backend, Supabase, GPU compute for the 3D pipeline, and
a Shopify widget for storefront integration.
